# Em toda letra E

Site em Streamlit com a matéria sobre o álbum e player das faixas.

## Rodar local
    pip install -r requirements.txt
    streamlit run app.py

## Publicar
1. Crie um repositório no GitHub e suba esta pasta (app.py na raiz).
2. Em https://share.streamlit.io entre com o GitHub > Create app > escolha o repositório, branch `main`, arquivo `app.py` > Deploy.

Obs.: o plano gratuito do Suno é pessoal e não comercial; ao deixar os MP3s num repositório público, confira os termos.
